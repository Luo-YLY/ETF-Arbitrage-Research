# Panel + Bokeh 双页面研究控制台

该控制台与现有 Streamlit 入口并行存在，完整保留两条相互独立的研究流程。

## 启动

在项目根目录运行：

```powershell
.\.conda\py314\python.exe -m panel serve panel_app.py --address 127.0.0.1 --port 8505 --allow-websocket-origin 127.0.0.1:8505 --allow-websocket-origin localhost:8505
```

常用地址：

- 默认进入均值回复页：`http://127.0.0.1:8505/panel_app`
- 直接进入套利模拟页：`http://127.0.0.1:8505/panel_app?page=executable`

跨境/港股套利当前暂停：境内多ETF五档采集列表不会出现港股ETF，Panel实盘套利页也不再
使用模拟港股盘口或模拟汇率生成执行结论。历史跨境入口与研究代码仅保留作归档，不属于当前
盘中操作流程。

左侧顶部可以在“实盘均值回复监控”和“实盘套利模拟”之间切换。切换时会停止隐藏页面的定时回放，主区域会整体替换，不保留另一条业务线的图表和表格。

均值回复页的研究日期使用日历控件，默认当天，可以选择任意日期，不受本地已有文件限制。
ETF 控件支持按六位代码或名称搜索，也允许直接输入目录外的新代码；当前日期尚无记录时显示
“等待采集或导入”，刷新后会在原日期直接接入新文件。模型参数和回放设置默认收起，PCF
准备日期会与侧栏研究日期联动。

## 实盘均值回复监控

该页面面向内网 Redis 最新价采集和收盘后 Premium 均值回复研究，包含：

- 深市 XML、沪市官方查询 JSON 的 PCF 本地读取、下载、上传和完整性校验；
- 多 ETF 真实行情后台采集，按 PCF 挂牌市场自动使用 `.SH/.SZ/.BJ/.HK` 后缀；
- 通过搜索框输入任意六位 ETF 代码并加入多标的监控列表；
- 采集任务启动、停止、状态、最新记录和日志查看；
- 自动发现 `tmp/observations/YYYYMMDD/{ETF}.jsonl`；
- 兼容读取 `outputs/data_check/YYYYMMDD/{ETF}/observations.csv`；
- ETF 最新价、Bid/Ask（数据存在时）、IOPV 和 Premium 增量回放；
- 默认每 3 秒检查采集文件并跟随最新记录，文件未变化时不会重复计算；
- 开仓阈值、平仓阈值、最长持有期和成本参数；
- 收盘后收敛率、30/60/300秒收敛率、收敛时间、MAE/MFE和逐笔价差捕获；
- 收盘回测上下联动图：折溢价、开平仓标记、持仓周期阴影与收敛研究指数共用时间轴；
- 回测图支持原始快照、30秒、1分钟和5分钟频率；
- 6/15/30/50bp等往返成本情景下的净价差捕获敏感性。

真实 Redis 暂无 Bid/Ask 时使用“指示性（最新价）”模式。页面中的曲线是 Premium 收敛
研究指数，不是账户净值；价差指数回撤也不是实盘组合最大回撤。

“实时观察”默认显示最新窗口，进度为“当前文件总数/当前文件总数”。关闭“跟随最新行情”或点击回放控制后，才会从文件开头进行历史回放。

## 实盘套利模拟

该页面面向带 Bid/Ask 和多档深度的境内ETF可执行申赎套利纸面模拟。配置区拆成两个页面：

- **数据采集**：使用独立的PCF选择器，多选境内ETF并启动后台五档采集。该页只写入
  `tmp/executable_recordings/YYYYMMDD/{ETF}.jsonl` 和机会摘要，不创建纸面成交。
- **套利模拟配置**：使用另一套PCF选择器，针对单只ETF回放完整五档采集文件，或切换为
  Redis实时五档纸面模拟。更换模拟ETF不会改动正在运行的多ETF采集任务。

当前运行入口只保留两类真实五档数据源：

- **完整五档采集文件回放**：默认流式读取采集器生成的嵌套JSONL，校验ETF代码、交易日、
  PCF版本和哈希。ETF及成分股盘口、时间戳和缺失状态原样进入质量门禁，不根据Last合成盘口。
- **Redis实时五档**：读取当前交易日Hash；连接来自 `SZ_REDIS_*` 环境变量。实时模拟页不
  重复写文件，原始快照由“数据采集”页统一保存。

PCF“官方下载”按ETF代码自动识别沪深市场，无需手工填写地址。沪市使用上交所官方查询；
深市根据ETF代码和交易日自动生成官方历史PCF地址，目录外新加入的深市ETF同样适用。

质量门禁按“市场阶段、数据源健康、单证券状态”分层处理。只有连续竞价阶段允许产生新机会；
开盘集合竞价、午休、收盘集合竞价和闭市仍展示快照，但不会因无盘口误判停牌。供应商明确
停牌状态才视为确认停牌，`T1/C1` 无盘口暂时只显示为疑似停牌；根据昨收和代码板块推算的
涨跌停会同时展示“中等置信度”和推断依据。

申购和赎回独立放行：申购检查ETF买一与成分股卖一，赎回检查ETF卖一与成分股买一。某个
方向缺少所需盘口只阻断该方向。交易日Hash的一次批量读取视为同一接收截面，证券自身
`ctime` 差异仅作事件时间诊断；数据源水位和单证券长时间不更新分别判定。

Panel入口已移除随机合成行情、价格种子、异常注入和旧版通用文件字段映射。页面保留PCF、
执行与交易摩擦、账户、一级市场和数据质量参数，并展示：

- ETF 价格、Bid/Ask、内部 IOPV 和无套利边界；价格图使用实际价格窄幅自动缩放，
  官方IOPV暂不绘制，右轴以首个有效ETF Last为0 bp显示相对开盘变化；
- ETF 与成分股多档盘口、申购/赎回篮子和容量；
- 申购与赎回机会、漏斗和拒绝原因；
- 纸面订单、成交、一级市场申赎、交易和 PnL；
- 数据质量、数据源健康状态、运行历史和 CSV/Parquet/JSON 导出。

默认只记录机会。只有主动打开“自动纸面交易”并关闭“只记录机会”后，系统才会生成纸面订单
和申赎请求；项目不连接真实券商交易柜台。跨境/港股套利当前暂停，不进入境内多ETF采集任务。

## 刷新方式

控制台使用轻量 Bootstrap 模板，并按需创建业务页面和当前标签。两页图表都复用持久化 Bokeh 数据源，以增量追加替代整页重建。开始、暂停、单步、重置和加速回放不会重新创建整张图，因此比 Streamlit 全页重跑更适合日内持续监控。
