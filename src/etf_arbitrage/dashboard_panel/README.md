# Panel + Bokeh 双页面研究控制台

该控制台与现有 Streamlit 入口并行存在，完整保留两条相互独立的研究流程。

## 启动

在项目根目录运行：

```powershell
.\.conda\py314\python.exe -m panel serve panel_app.py --address 127.0.0.1 --port 8505
```

常用地址：

- 默认进入均值回复页：`http://127.0.0.1:8505/panel_app`
- 直接进入套利模拟页：`http://127.0.0.1:8505/panel_app?page=executable`

跨境ETF研究使用独立入口，不与原沪深均值回复页面混在同一个入口：

```powershell
.\.conda\py314\python.exe -m panel serve panel_hk_app.py --address 127.0.0.1 --port 8506
```

- 跨境ETF控制台：`http://127.0.0.1:8506/panel_hk_app`
- 直接进入跨境套利模拟：`http://127.0.0.1:8506/panel_hk_app?page=executable`
- 当前主线：默认研究 `159920.SZ` 及同类境内上市跨境ETF；2800/82800仅保留历史对照。
- 官方 PCF：复用深交所XML PCF自动下载与严格校验，不使用第三方成分数据替代官方清单。
- 行情主路径：境内ETF与港股成分统一从内网Redis读取；历史页只回放Redis采集生成的本地文件。
- IOPV口径：159900“申赎现金”是清算用虚拟证券，不进入港股篮子求和；申购使用成分卖一和
  FX卖价，赎回使用成分买一和FX买价。
- 执行边界：港股通合资格名单、Redis字段映射、代理买卖、多退少补与T+交收未完成前，
  结果强制为 `DEGRADED / INDICATIVE`，只识别机会，不生成真实交易。
- 跨境均值回复：读取Redis分钟采集形成的标准化观察文件；没有记录时显示“等待采集或导入”。
- 跨境套利模拟：可用Redis最新价、本地Redis采集记录或完全模拟作为起点；多档深度、代理
  买卖和现金退补尚未取得真实输入时仍为 `INDICATIVE_PAPER`。159900虚拟申赎现金会从
  模拟估值篮子中排除，避免重复计价。

左侧顶部可以在“实盘均值回复监控”和“实盘套利模拟”之间切换。切换时会停止隐藏页面的定时回放，主区域会整体替换，不保留另一条业务线的图表和表格。

均值回复页的研究日期使用日历控件，默认当天，可以选择任意日期，不受本地已有文件限制。
ETF 控件支持按六位代码或名称搜索，也允许直接输入目录外的新代码；当前日期尚无记录时显示
“等待采集或导入”，刷新后会在原日期直接接入新文件。模型参数和回放设置默认收起，PCF
准备日期会与侧栏研究日期联动。

## 实盘均值回复监控

该页面面向内网 Redis 最新价采集和收盘后 Premium 均值回复研究，包含：

- 深市 XML、沪市官方查询 JSON 的 PCF 本地读取、下载、上传和完整性校验；
- 多 ETF 真实行情后台采集，按 PCF 挂牌市场自动使用 `.SH/.SZ/.BJ/.HK` 后缀；
- 通过搜索框输入任意六位 ETF 代码并加入多标的监控列表；
- 采集任务启动、停止、状态、最新记录和日志查看；
- 自动发现 `tmp/observations/YYYYMMDD/{ETF}.jsonl`；
- 兼容读取 `outputs/data_check/YYYYMMDD/{ETF}/observations.csv`；
- ETF 最新价、Bid/Ask（数据存在时）、IOPV 和 Premium 增量回放；
- 默认每 3 秒检查采集文件并跟随最新记录，文件未变化时不会重复计算；
- 开仓阈值、平仓阈值、最长持有期和成本参数；
- 收盘后收敛率、30/60/300秒收敛率、收敛时间、MAE/MFE和逐笔价差捕获；
- 收盘回测上下联动图：折溢价、开平仓标记、持仓周期阴影与收敛研究指数共用时间轴；
- 回测图支持原始快照、30秒、1分钟和5分钟频率；
- 6/15/30/50bp等往返成本情景下的净价差捕获敏感性。

真实 Redis 暂无 Bid/Ask 时使用“指示性（最新价）”模式。页面中的曲线是 Premium 收敛
研究指数，不是账户净值；价差指数回撤也不是实盘组合最大回撤。

“实时观察”默认显示最新窗口，进度为“当前文件总数/当前文件总数”。关闭“跟随最新行情”或点击回放控制后，才会从文件开头进行历史回放。

## 实盘套利模拟

该页面面向带 Bid/Ask 和多档深度的可执行申赎套利纸面模拟，支持三类行情来源：

- **模拟行情**：基于 PCF 生成 ETF、成分股、IOPV 和多档盘口，可注入溢价、折价、深度不足、陈旧、缺失、停牌、涨跌停、解码错误和序号断档等场景；
- **上传/读取历史行情**：支持 CSV、JSON、JSONL 和 Parquet，可上传文件，也可填写本地文件、目录或通配符，并支持字段映射；
- **标准化 Redis 行情**：预留实时标准化快照接口，默认关闭，不影响模拟和文件回放。

侧边栏“模拟价格来源”默认选择“本地历史数据（逐条回放）”：控制台流式读取
`tmp/recordings/YYYYMMDD/ETF代码.jsonl`，逐条保留ETF与成分股Last历史轨迹和原始时间戳，
并为每个时点合成Bid/Ask与多档深度，不要求当前机器连接Redis，也不会把数百MB文件一次性
载入内存。也可手工指定采集文件、选择完全模拟，或在内网环境显式读取Redis最新价。历史价格
轨迹来自采集文件，盘口深度、冲击和成交仍由模拟器生成，不会把合成盘口标记成真实盘口。

页面保留完整的 PCF、执行、账户、一级市场和数据质量参数，并展示：

- ETF 价格、Bid/Ask、内部 IOPV 和无套利边界；价格图使用实际价格窄幅自动缩放，
  官方IOPV暂不绘制，右轴以首个有效ETF Last为0 bp显示相对开盘变化；
- ETF 与成分股多档盘口、申购/赎回篮子和容量；
- 申购与赎回机会、漏斗和拒绝原因；
- 模拟订单、成交、一级市场申赎、交易和 PnL；
- 数据质量、数据源健康状态、运行历史和 CSV/Parquet/JSON 导出。

默认只记录机会。只有主动打开“自动纸面交易”并关闭“只记录机会”后，系统才会生成模拟订单和申赎请求；项目不连接真实券商交易柜台。

## 刷新方式

控制台使用轻量 Bootstrap 模板，并按需创建业务页面和当前标签。两页图表都复用持久化 Bokeh 数据源，以增量追加替代整页重建。开始、暂停、单步、重置和加速回放不会重新创建整张图，因此比 Streamlit 全页重跑更适合日内持续监控。
