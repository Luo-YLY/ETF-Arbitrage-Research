# Panel + Bokeh 双页面研究控制台

该控制台与现有 Streamlit 入口并行存在，完整保留两条相互独立的研究流程。

## 启动

在项目根目录运行：

```powershell
.\.conda\py314\python.exe -m panel serve panel_app.py --address 127.0.0.1 --port 8505
```

常用地址：

- 默认进入均值回复页：`http://127.0.0.1:8505/panel_app`
- 直接进入套利模拟页：`http://127.0.0.1:8505/panel_app?page=executable`

左侧顶部可以在“实盘均值回复监控”和“实盘套利模拟”之间切换。切换时会停止隐藏页面的定时回放，主区域会整体替换，不保留另一条业务线的图表和表格。

## 实盘均值回复监控

该页面面向内网 Redis 最新价采集和收盘后 Premium 均值回复研究，包含：

- PCF 本地读取、官方下载、XML/ZIP 上传和完整性校验；
- 多 ETF 真实行情后台采集，默认使用 Redis 的 `.SZ` 代码后缀；
- 采集任务启动、停止、状态、最新记录和日志查看；
- 自动发现 `tmp/observations/YYYYMMDD/{ETF}.jsonl`；
- 兼容读取 `outputs/data_check/YYYYMMDD/{ETF}/observations.csv`；
- ETF 最新价、Bid/Ask（数据存在时）、IOPV 和 Premium 增量回放；
- 开仓阈值、平仓阈值、最长持有期和成本参数；
- 收盘后均值回复交易记录、收益、Sharpe、最大回撤、胜率和持有期。

真实 Redis 暂无 Bid/Ask 时使用“指示性（最新价）”模式。此处的累计收益是 Premium 头寸收敛研究结果，不等同于真实申赎套利收益。

## 实盘套利模拟

该页面面向带 Bid/Ask 和多档深度的可执行申赎套利纸面模拟，支持三类行情来源：

- **模拟行情**：基于 PCF 生成 ETF、成分股、IOPV 和多档盘口，可注入溢价、折价、深度不足、陈旧、缺失、停牌、涨跌停、解码错误和序号断档等场景；
- **上传/读取历史行情**：支持 CSV、JSON、JSONL 和 Parquet，可上传文件，也可填写本地文件、目录或通配符，并支持字段映射；
- **标准化 Redis 行情**：预留实时标准化快照接口，默认关闭，不影响模拟和文件回放。

页面保留完整的 PCF、执行、账户、一级市场和数据质量参数，并展示：

- ETF 价格、Bid/Ask、官方/内部 IOPV 和无套利边界；
- ETF 与成分股多档盘口、申购/赎回篮子和容量；
- 申购与赎回机会、漏斗和拒绝原因；
- 模拟订单、成交、一级市场申赎、交易和 PnL；
- 数据质量、数据源健康状态、运行历史和 CSV/Parquet/JSON 导出。

默认只记录机会。只有主动打开“自动纸面交易”并关闭“只记录机会”后，系统才会生成模拟订单和申赎请求；项目不连接真实券商交易柜台。

## 刷新方式

两页图表都复用持久化 Bokeh 数据源，以增量追加替代整页重建。开始、暂停、单步、重置和加速回放不会重新创建整张图，因此比 Streamlit 全页重跑更适合日内持续监控。
